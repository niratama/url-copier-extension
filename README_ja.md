# URL Copier Extension

現在のタブ（またはすべてのタブ）のURLとタイトルを、カスタマイズ可能な様々な形式でコピーできるChrome拡張機能です。

[English README is here](README.md)

## 機能

- **カスタマイズ可能なテンプレート**: `{{title}}` と `{{url}}` のプレースホルダーを使って独自のフォーマットを定義できます。
- **ポップアップメニューアクセス**: 拡張機能アイコンをクリックすると、テンプレート選択用のポップアップメニューが開きます。
- **コピー対象切り替え**: ポップアップ内のタブで「現在のタブをコピー」/「すべてのタブをコピー」を切り替えられます。
- **オプションへの導線**: ポップアップ内の **オプション** ボタンから設定ページを開けます。
- **国際化対応**: 英語と日本語に対応しています。
- **キーボードショートカット**:
  - `Alt+C`: 最後に使用したテンプレートでコピーします。
  - `Alt+P`: ポップアップメニューを開き、テンプレートを選択してコピーします。
  - `Alt+1`: スロット1に割り当てられたテンプレートでコピーします。
  - `Alt+2`: スロット2に割り当てられたテンプレートでコピーします。

## デフォルトテンプレート

- **Markdown**: `[{{title}}]({{url}})`
- **Markdown 2**: `{{title}} <{{url}}>`
- **HTML**: `<a href="{{url}}">{{title}}</a>`
- **Text**: `{{title}} {{url}}`
- **Two line text**:
  ```
  {{title}}
  {{url}}
  ```

## インストール方法

1.  このリポジトリをクローンまたはダウンロードします。
2.  Chromeを開き、`chrome://extensions/` にアクセスします。
3.  右上の **デベロッパーモード** を有効にします。
4.  **パッケージ化されていない拡張機能を読み込む** をクリックします。
5.  この拡張機能が含まれるディレクトリを選択します。

## アイコンアセット

アイコンPNGは `generate_icons.ps1` で生成しています。Chrome Web Store 用の通常アイコンと、ツールバー用 action アイコンで別のジオメトリを使い分けており、現在は `icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`、`icon.png`、`action-16.png`、`action-24.png`、`action-32.png`、`action-48.png` を出力します。

再生成する場合は、次を実行します。

```powershell
./generate_icons.ps1
```

## 使い方

1.  ツールバーの拡張機能アイコンを **左クリック** すると、テンプレート選択ポップアップが開きます。
2.  上部タブで **現在のタブをコピー** / **すべてのタブをコピー** を選択します。
3.  テンプレートを選択すると、選択中の対象に対してコピーが実行されます。
4.  ポップアップ内の **オプション** ボタン、または拡張機能のオプション画面からテンプレートの追加・編集・削除が可能です。
5.  **キーボードショートカット**: `Alt+P` でポップアップを開けます。ポップアップ内では `←` / `→` でコピー対象タブを切り替え、`↑` / `↓` でテンプレート選択、`Enter` でコピー、`Esc` で閉じます。オプションページで `Alt+1` と `Alt+2` にお気に入りテンプレートを割り当てることも可能です。
